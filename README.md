# Air Quality R Programming Project

This repository contains an air quality analysis workflow built with R. It includes data cleaning, exploratory data analysis, and modeling scripts.

## Repository Structure

- data/ - raw and processed data used by the analysis.
- scripts/ - R scripts for cleaning, visualization, and modeling.
- report/ - generated reports, figures, and summary outputs.

## Getting Started

1. Place your air quality dataset files in data/.
2. Run scripts/data_cleaning.R to clean and prepare the data.
3. Run scripts/eda_visualization.R to generate exploratory figures.
4. Run scripts/modeling.R to fit models and evaluate results.

## Notes

- Keep data/ and report/ organized by dataset and output type.
- Update the README.md files inside each folder with dataset and report details.
